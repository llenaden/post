# Конструктор каруселей

Мобильное веб‑приложение для тренера: собирает карточки для карусели в Instagram / Telegram / VK из простых ответов на вопросы и отдаёт готовые PNG 1080×1080.

Один файл `index.html`, без сборки и сервера — открывается в браузере и работает на GitHub Pages.

## Что умеет

- **Анкета один раз**: имя, ник и соцсеть (иконка рядом с ником на каждой карточке), направление, текст «о себе», фото лица (с обрезкой в круг) и фото в рост.
- **Обложка** — 9 шаблонов: фото целиком, фото сверху, только текст, фото в круге, фото с плашкой, со стикером, выделение, минимал с пятном, карточка на фото.
- **Внутренние карточки** — 16 шаблонов: текст, список с иконками, цифры, фото, акцент, шаги, миф и факт, отзыв, упражнение, текст на фото, сетка пунктов (с фото и сноской), заметка, по центру, фото с выносками, отзыв на фото (с фото клиента), расписание дня.
- **Финальная карточка «обо мне»** — 3 варианта (или без неё). Можно сделать и одиночный пост — 0 внутренних карточек.
- Карточки открываются **заполненными примером** шаблона; есть кнопки «Загрузить пример» и «Очистить карточку».
- Выделение слова цветом: `**слово**` в заголовке.
- **Типограф**: неразрывные пробелы после предлогов и союзов, «ёлочки», тире — и на карточках, и в интерфейсе.
- Единая дизайн‑система карточек: фирменная палитра, одна шкала шрифтов, поля 72 px, предупреждение «Текст не помещается».
- **Сохранение**: по одной картинке, «Сохранить все», на компьютере — zip‑архивом.

## Как запустить

Локально достаточно открыть `index.html` в браузере. Чтобы работала память браузера (IndexedDB) так же, как на хостинге, лучше через локальный сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

### GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы этой папки.
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

На телефоне его можно добавить на экран «Домой» — будет иконка и полноэкранный режим.

## Где хранятся данные

Всё хранится только в браузере пользователя, на сервер ничего не уходит.

| Что | Где |
| --- | --- |
| Анкета с фото, последняя карусель, фото карусели | IndexedDB (база `carousel-photos`, хранилища `kv` и `img`) |
| Лёгкая копия анкеты и черновика без фото — для мгновенного открытия | localStorage: `carousel-profile-v2`, `carousel-draft-v3` |

Приложение просит браузер сделать хранилище постоянным (`navigator.storage.persist()`), чтобы данные не удалялись при нехватке места. Данные привязаны к адресу сайта: при переезде на другой домен анкету придётся заполнить заново.

## Сохранение картинок

- Внутри Claude используется встроенное API скачивания (`window.claude.use('downloads')`).
- На обычном сайте: на телефоне открывается системное меню «Поделиться» → «Сохранить изображения», на компьютере файлы скачиваются как обычно.
- Если ничего из этого недоступно, показывается окно с картинками для сохранения долгим нажатием.

## Устройство кода

Всё в `index.html`: стили, разметка и скрипт.

- `T` — шкала размеров карточек (поля, радиусы, кегли), `BR` — фирменная палитра, `BGS` — фоны.
- `COVERS`, `INNERS`, `FINALS` — списки шаблонов; `FIELDS` — какие поля у шаблона; `LABELS` — подписи и подсказки полей; `DEMO_TXT` / `DEMO_IMG` — тексты и фото примеров.
- `renderCover`, `renderInner`, `renderAbout` и объект `REF_INNER` — отрисовка карточек на `<canvas>` 1080×1080.
- `editScreen` — экран редактирования карточки; `imgField`, `bgField` — выбор фото и фона.

### Как добавить шаблон внутренней карточки

1. Добавьте `['i-mytpl','Название']` в `INNERS` (или `INNERS_EXTRA`).
2. Укажите поля в `FIELDS['i-mytpl']`, при необходимости подписи в `LABELS` и фон по умолчанию в `DEF_BG`.
3. Добавьте текст примера в `DEMO_TXT['i-mytpl']`.
4. Напишите функцию отрисовки `'i-mytpl'(ctx,c){ … }` в `REF_INNER`, используя `T`, `palette()`, `stack()`, `wrap()`, `drawLines()`.
